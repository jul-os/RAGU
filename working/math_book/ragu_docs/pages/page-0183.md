3. Построение начальной симплекс-таблицы.

Для получения начального допустимого базисного решения пря-
мой задачи линейного программирования обычно используется метод
искусственного базиса. Однако, если не представляет затруднений по-
строить симплекс-таблицу, допустимую относительно двойственной
задачи, то, применяя двойственный симплекс-алгоритм, можно найти
решение прямой задачи, не прибегая к методу искусственного базиса.
Это, как правило, существенно сокращает необходимое число преоб-
разований симплекс-метода.

Построение начальной симплекс-таблицы, допустимой для двой-
ственной задачи, наиболее просто, если в соотношении (4.80) все
с;20. Тогда, очевидно, первая симплекс-таблица будет допустимой
относительно двойственной задачи, хотя при наличии ограничений
(4.81) с Ь; <0 не допустимой для прямой задачи.

Использование такого подхода при решении прямой задачи ли-
нейного программирования демонстрирует пример 4.17.
