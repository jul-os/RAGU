6. Большому числу людей необходимо сделать анализ крови. Рассмотрим
следующий способ организации анализов.

Кровь А человек смешивается, и анализируется смесь. При отрицатель-
ном результате одного этого анализа достаточно для данных k человек. Если
же результат положителен, то кровь каждого из них исследуется отдельно, и
для К человек требуется К +1 анализов.

Вероятность положительного результата анализа одна и та же для всех
людей и равна р, а результаты анализов для различных людей статистически
независимы.

Оптимизировать описанный способ организации обследования, принимая
во внимание необходимое для этого число анализов.

числа № обследуемых людей описанным способом среднее число анализов,
приходящееся на группу из А человек, сходится по вероятности к математи-
ческому ожиданию этого числа.
