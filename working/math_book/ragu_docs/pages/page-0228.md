Во многих реальных ситуациях аналитические зависимости между
переменными, входящими в условие задачи математического програм-
мирования, бывают неизвестны и соответствующие функции задаются
с помощью таблиц, т.е. дискретно. Это обусловливает дискретность
таких задач.

Если упомянутые табличные функции заданы с постоянным шагом
дискретизации, то при необходимости, изменяя масштаб переменных,
можно перейти к целочисленной задаче оптимизации.
