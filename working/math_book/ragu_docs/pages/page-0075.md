3.2. ПРИМЕР ПРАКТИЧЕСКОЙ ЗАДАЧИ БЕЗУСЛОВНОЙ
МИНИМИЗАЦИИ (МЕТОД НАИМЕНЬШИХ КВАДРАТОВ)

Пусть производится опыт, целью которого является исследование
функциональной зависимости между поддающимися измерению величи-
нами у и х, например зависимости силы тока через диод от приложенного
к нему напряжения. В эксперименте проводится N независимых измере-
ний. В результате получаются нары чисел (x;, y), [=1,..., №.

Часто вид зависимости (линейная, квадратичная, экспоненциаль-
ная и т.п.) у отх заранее известен из теоретических соображений, а из
опыта требуется установить только значения некоторых параметров
этой зависимости. Кроме того, весьма типичной для практики являет-
ся задача сглаживания экспериментальных данных, в которой требует-
ся для данного вида функциональной зависимости подобрать парамет-
ры, ее определяющие, так, чтобы по возможности более точно отра-
зить наблюдаемую в экспериментах зависимость у отх. При этом сле-
дует сгладить незакономерные, случайные уклонения, связанные с не-
избежными погрепгностями измерений.
